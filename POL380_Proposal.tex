\section{Proposed Topic}

Why do some democracies protect domestic producers more than others? I aim to study whether factors such as exports, unemployment rates, GDP, and inflation rates causally shape how protectionist a country's trade policy is. Other analyses \citep{Ehrlich2007, Gawande2000, HeniszMansfield2006} often test for the impact of interactions between firms and policymakers and domestic institutions on protectionism, while holding economic conditions constant, meaning that additional testing must be done in order to determine whether the economic conditions themselves also impact the degree of protectionism. Using a panel of many countries spanning several decades, I aim to estimate the effect of each economic factor using double machine learning (DML), which lets flexible learners such as random forests and neural networks estimate causal parameters in the presence of complex confounding variables \citep{DML}.  

This project aims to answer the question \textbf{Which domestic economic factors cause countries to adopt more protectionist trade policies, and how robust are these effects?} by testing a variety of hypotheses regarding protectionism. 

\paragraph{H1 (Exports): } Exports being a higher percentage of GDP decrease protectionism. Countries that export a significant amount of products abroad prefer other countries to keep their markets open, and worry that raising their own tariffs may lead to retaliation. 

\paragraph{H2 (Unemployment):} Increased unemployment rates cause increased protectionism. Free trade allows products to be imported from abroad, meaning that local industries may suffer, leading to high unemployment rates. Therefore, those suffering from unemployment and the firms forced to lay off workers will advocate for protectionism in order to maintain local jobs. 

\paragraph{H3 (GDP per Capita):} Increases in GDP per capita causes increased protectionism. \textcolor{red}{need help with this one}

\paragraph{H4 (Total GDP in US\$):} A higher total GDP causes increased protectionism. Small economies are unable to produce all goods, therefore imports are essential. Larger economies are able to produce more goods domestically and can afford for trade to be closed \textcolor{red}{Is this right? Check if Ehrlich cited anything useful and look at that paper.} 

\paragraph{H5 (Inflation):} Increased inflation rates cause decreased protectionism. Inflation is defined by an increase in domestic prices. Decreased protectionism allows for the importing of cheaper goods, helping to reduce prices. 

\noindent For the sake of this analysis, the level of protectionism will be quantified using tariff rates. Tariffs are directly set by policymakers, meaning that changes in tariff rates directly reflect policy choices.

\section{Prior Work}

Prior analyses argue that politics drives protectionism, rather than economics. In the Grossman-Helpman model \citep{GH_Model}, governments weigh campaign contributions from organized industries against social welfare. \cite{Gawande2000} tested this on US non-tariff barriers across manufacturing industries and found broad support for the model. A second set of studies ask how political institutions affect these pressures. \cite{Ehrlich2007} finds that a larger number number of electoral districts, a larger number of political parties, presidentialism, and left-wing governments all cause increased protectionism. \cite{HeniszMansfield2006} focuses on how institutions change the effect of economic conditions. All of these studies focus on the impacts of interactions between lobbyists and policymakers, and/or the institutions involved. This suggests that more research needs to be done into the impact of the economic conditions themselves. Do the economic conditions that drive these interactions also have a role, or are the interactions the root cause? This project seeks to study the impact of various economic conditions on the level of protectionism.

\section{Proposed Methods and Current Progress} 

Double Machine Learning (DML) is based on the Frisch-Waugh-Lovell (FWL) Theorem \citep{FrischWaugh1933, Lovell1963}, which says that interactions between variables can be combatted using multiple linear regression analyses. First, regress the treatment parameter $D$ on the independent variable you'd like to test ($X_{T}$) to find the treatment residual ($r_T$). Then, regress the outcome ($Y$) on the nuisance variables ($X_{N}$) to obtain the nuisance residual ($r_N$), giving you the variation of the outcome independent of $X_T$. Finally, regress $r_N$ on $r_T$ to obtain the multivariate regression coefficient. DML takes the FWL Theorem a step further, expanding it beyond linear relationships. DML replaces linear regression with any machine learning algorithm, enabling the FWL process to be used on models in which the variables are not related linearly.

# import required modules

import doubleml as dml
from sklearn.ensemble import RandomForestRegressor
import pandas as pd


# Import the data

data = pd.read_csv('ProtectionismDataset.csv')

data.pop('Country') # Ditch country and year since I don't want them impacting results 
data.pop('Year') 

# Define independent and dependent variables 

dep_var = 'Tariff'

ind_vars = ['Exports', 'Unemployment', 'GDP_PerCapita', 'GDP_US', 'Inflation', 'NoParties']

results = {} # dictionary for storage

# Loop through independent variables

for var in ind_vars:
    measured_var = var
    other_vars = [v for v in ind_vars if v != measured_var]

    dml_data = dml.DoubleMLData(data, y_col = dep_var, d_cols = measured_var, x_cols = other_vars) # Create data structure

    # define nuisance learners with Random Forest
    #Figure out what parameters make sense 
    learner_l = RandomForestRegressor(n_estimators=100, max_depth=5, random_state=42) # predicting target from controls
    learner_m = RandomForestRegressor(n_estimators=100, max_depth=5, random_state=42) # predict treatment from controls 

    # Partial Linear Regression Model 
    dml_plr = dml.DoubleMLPLR(dml_data, ml_l = learner_l, ml_m = learner_m, n_folds = 5) 
    dml_plr.fit()

    results[measured_var] = dml_plr.summary

# Combine results into a single DataFrame

resultsDF = pd.concat(results)

resultsDF.to_csv('DML_Results.csv')
